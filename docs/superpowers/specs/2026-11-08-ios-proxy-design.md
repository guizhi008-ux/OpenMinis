# iOS 应用内网络代理设计（用户已确认）

2026-11-08：用户确认按此范围实施，包括严格模式下停用无法纳入代理的可控系统功能。

## 用户需求

iPhone；手动代理与小火箭订阅都要；覆盖 OpenMinis 全部对外联网，包括
内部 Linux 小系统；只影响 OpenMinis，不接管其他 App。

## 目标与验收

- 设置提供关闭、手动代理、订阅节点三种模式。
- 手动 HTTP CONNECT、SOCKS5 及可选认证；HTTPS 订阅导入、更新、选择、
  删除、连接测试。首期建议解析纯文本/整体 Base64 的 SS、VMess、VLESS、
  Trojan 列表。核心不能完整表达的参数、插件或协议明确报不支持。
- 应用控制的公网 TCP/UDP/DNS 统一代理：模型、语音图片、令牌刷新、
  浏览器/WebApp、MCP、下载、远程备份和 Linux 小系统。
- 小系统在 socket 层接管 IPv4/IPv6、TCP/UDP/DNS，覆盖忽略代理环境变量
  的程序；验证 curl、apk、pip、git、ssh 与原始 socket 程序的实际出口。
- 默认严格模式：节点故障、配置缺失、未知路由或入口停止时受管业务失败，
  不自动直连。节点不支持 UDP 则拒绝该流量，DNS 可走代理内 TCP/DoH。
- 只修改应用及小系统的网络入口，不设置手机代理、不安装系统 VPN、
  不依赖 MDM，不修改其他 App。

## iOS 边界与建议默认值

以下边界及建议默认值随本方案确认；具体实现及验证结果另见实施记录。

- iCloud/CloudKit、APNs、系统托管登录页属于系统服务，普通应用不能强制
  全部代理。严格模式停用可控制的云同步、网络委托及系统登录入口；安全可行
  的授权可另适配受管内置浏览器。不能声称撤回已委托任务或接管共享 APNs。
- 回环内部服务、代理自身连接上游服务器是必要底层路径，避免递归代理。
  LAN 不默认绕过；蓝牙、HomeKit 等系统设备功能单独标明限制。
- 不支持的原始 IP/ICMP 等流量明确拒绝或标注系统限制。
- 节点域名首次解析及订阅首次下载有 bootstrap 问题：优先当前可用代理，
  没有时提供离线导入；需要直连时在界面明确提示，不静默执行。
- 不提供服务器、订阅、模型账号，也不取消服务商收费和额度。

## 方案与用户选择

仅配置 URLSession 和环境变量不能覆盖小系统，排除。
系统 VPN 隧道可能影响其他 App，用户明确排除。
采用应用各网络入口与小系统 socket 层接管的路线。

## 源码调查

- iOS URLSession 入口分散，WebKit 有多个数据存储和窗口入口。
- `deps/rclone-mobile/nethub` 已有本地 SOCKS/HTTP、上游代理、路由标签、
  UDP/DNS 和透明转发辅助代码；iOS 未找到完整接线，不能视为功能已具备。
- 现有代理路由会让部分 UDP/DNS 直连，必须补齐严格模式。
- 固定 iSH 提交 `0fd17a135e78b7a0cf08a4f5831217bbb76ed22f` 的
  `fs/sock.c` 仍调用宿主 connect，未发现 xnet 接口。Go 注释提到的
  透明钩子不能当作当前内核已有实现。
- rclone/Tailscale 已共用 Go c-archive；现有构建脚本明确不能再链接
  第二个 Go runtime。代理核心必须放入同一 Go 构建单元。

## 架构建议

- 验证并锁定 sing-box 核心版本及构建标签，集成既有 Go 单元，检查依赖、
  许可及 iOS 构建；扩展 nethub 出口、UDP/DNS 与严格失败处理。
- 回环入口每进程随机认证。原生请求统一工厂，包括 SDK、WebSocket、下载。
  所有 WKWebsiteDataStore 配置代理，新窗口和 WebApp 同样覆盖。
- 为 iSH 添加配置/启停 C API，处理 connect、sendto/sendmsg、recvfrom/
  recvmsg、非阻塞、poll/epoll、取消与 DNS；SOCKS UDP 必须保留源地址。
  交付绑定原提交的可重现补丁，不能依赖私有源码。
- Go 内 rclone 的 HTTP 和非 HTTP（SFTP/SMB/FTP 等）连接都要接管；
  审计 Tailscale 和内网路径，不能在严格模式下隐式旁路。
- 切换节点取消受管连接并重建会话，不能仅 reset；保留流式超时、网络切换
  清理及后台恢复检查。入口恢复前不得恢复业务联网。
- 凭据、订阅和敏感节点参数存 Keychain，不默认同步、备份或写入诊断。
  订阅更新原子保存，失败保留旧配置；选中节点删除时停止并提示重新选择。
